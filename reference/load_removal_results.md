# Load results from a previous \`remove_erroneous_obs()\` run

Load results from a previous \`remove_erroneous_obs()\` run

## Usage

``` r
load_removal_results(run_id)
```

## Arguments

- run_id:

  Character. The \`run_id\` used in \[remove_erroneous_obs()\].

## Value

The results list as saved by \[remove_erroneous_obs()\].
